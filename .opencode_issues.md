# Open issues

- [active] scripts/train_gpt2.py resume explicit-flag detection compares parsed values to parser defaults, so a flag explicitly set to the default (e.g. --val-frac 0.005 / --seq-len 1024) is treated as unspecified and silently replaced by the checkpoint value. Fix by collecting option dests from CLI tokens (including negated aliases and --flag=value) and config keys, then pass that set to restore_*.
- [active] scripts/data_pipeline.py PackedStream iterates a HuggingFace IterableDataset with `__iter__`, which already shards across DataLoader workers; its own worker filter then keeps ~1/n_workers^2 of the corpus. Iterate via the non-worker-sharded `ds.iter(batch_size=1)` API and flatten, preserving global hash-based dedup routing.
- [active] adasquash/diagnostics.py gradient explosion threshold uses max(1e4, explosion_factor*grad_clip), contradicting the documented clip-relative threshold; a norm 500x the clip with the default factor 100 is not flagged. Use explosion_factor*grad_clip whenever grad_clip is given, retaining the absolute 1e4 fallback only without a clip.
