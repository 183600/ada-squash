**File**: `scripts/ablation.py` (FACTORIAL_SPEC), `adasquash/norms.py`
**Problem**: The 2x2 factorial for per-channel × depth used fused DyT-D kernels for "depth" cells but plain-autograd for "per_channel" cells, conflating the axis with implementation differences.
**Fix Applied**: 
- Added `dytd_tanh` (plain-autograd DyT-D with tanh) to `adasquash/norms.py`
- Updated FACTORIAL_SPEC to use `dytd_tanh_k0` and `dytd_tanh_full` for all cells in the per-channel × depth tanh factorial
- Added 2x2x2 factorial design for per-channel × depth × softsign (8 cells)
- The 2x2x2 has inherent confound (tanh arm uses different norm class than softsign arm for per-channel toggle) so it's documented but not strictly validated
- Validation now passes with clean 2x2 factorial
