# Phase issues (temporary, delete before finishing)

1. [efficiency] `efficiency_verdict` still certifies cost when the caller
   supplies fewer than two paired rounds but also supplies
   `cost_ratio_stderr=0.0`. The `cost_ratio_n` guard only checks that a stderr
   is present, so `n=0/1` gets `df=max(1, n-1)` and a zero-width CI
   `[cost, cost]`, marking an unsupported measurement as certified/viable.
   A supplied round count < 2 must fail closed regardless of stderr.

2. [data] `_cache_matches` trusts a sidecar without `sha256` whenever it has
   a `bytes` field (`if not sha: return expected_bytes is not None`). The
   docstring promises reuse only when byte size and sha256 match, so a
   same-size edited cache with a bytes-only sidecar is silently accepted.
   Version-2 sidecars always write both fields; missing/empty sha must fail
   closed, and malformed byte counts must trigger a rebuild rather than crash.
