# Open issues

- [active] scripts/train_gpt2.py resume explicit-flag detection compares parsed values to parser defaults, so a flag explicitly set to the default (e.g. --val-frac 0.005 / --seq-len 1024) is treated as unspecified and silently replaced by the checkpoint value. Fix by collecting option dests from CLI tokens (including negated aliases and --flag=value) and config keys, then pass that set to restore_*.
- [active] scripts/data_pipeline.py PackedStream iterates a HuggingFace IterableDataset with `__iter__`, which already shards across DataLoader workers; its own worker filter then keeps ~1/n_workers^2 of the corpus. Iterate via the non-worker-sharded `ds.iter(batch_size=1)` API and flatten, preserving global hash-based dedup routing.
- [active] adasquash/diagnostics.py gradient explosion threshold uses max(1e4, explosion_factor*grad_clip), contradicting the documented clip-relative threshold; a norm 500x the clip with the default factor 100 is not flagged. Use explosion_factor*grad_clip whenever grad_clip is given, retaining the absolute 1e4 fallback only without a clip.
- [active] adasquash/model.py:_ce_scratch and adasquash/attention.py:_logit_scratch reuse a buffer created under torch.inference_mode() in a later grad-enabled call, causing "Inplace update to inference tensor outside InferenceMode". Invalidate inference tensors on lookup like the RoPE/cast caches already do.
- [active] scripts/run_needle.py and scripts/eval_downstream.py compare only the prompt context length with the trained seq_len, ignoring the secret's decode overhead; a 512-token context plus 2 scoring positions is forwarded at 514 positions but labeled in-distribution. Include overhead in exceeds_trained_seq_len / warning.
- [active] adasquash/attention.py:_logit_stats returns all-zero stats when exactly one causal logit is valid (B*H*T*(T+1)/2 == 1): the guard uses <= 1 instead of == 0, so the only logit's mean/max are silently reported as zero. Keep the zero return only for an empty sweep and leave std at 0 when n=1.
- [active] adasquash/utils.py MaxAbsMeter._peak and the shared _KURTOSIS_WORKSPACES buffers can be allocated under torch.inference_mode() and then updated in place after the meter is used for training, raising "Inplace update to inference tensor outside InferenceMode". Clone/drop stale inference tensors on reuse.
- [active] scripts/data_pipeline.py applies --exclude-test-hash-file to the test split even when val_frac=0, although that ledger is derived from a validation split that does not exist (train_gpt2.py and the group-ledger path already gate it on val_frac > 0). Gate the val->test hash ledger on has_val_split.
- [active] scripts/eval_downstream.py accepts a run with neither --tasks nor --needle-test, writes an eval_results.json/manifest with no measured metric, and marks the manifest status "finished" with exit 0. Reject the empty evaluation before loading the checkpoint.
- [active] scripts/train_gpt2.py _explicit_arg_names does an exact option-string lookup, so argparse-accepted unambiguous prefixes (--val-f for --val-frac) are not treated as explicit and resume silently restores the checkpoint value. Resolve spellings through parser._parse_optional.
- [active] scripts/check_w8a8_ppl.py _explicit_cli_names only recognizes exact option spellings, so argparse-accepted prefixes (--val-f for --val-frac) are treated as unspecified and the checkpoint's val_frac is used instead. Resolve through the parser like train_gpt2.
- [active] scripts/train_gpt2.py _ARCH_ARGS (and therefore _RESUME_RUN_ARGS) omits gradient_checkpointing, so resuming a checkpoint trained with --gradient-checkpointing silently rebuilds and trains without it. It is part of the model config recorded in checkpoint args; restore it with the other architecture flags.
